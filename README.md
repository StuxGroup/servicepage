# Servicepage

A clean and simple placeholder page for a Stux.Group service that hasn't been set up yet.

## Overview

This repository contains a lightweight HTML page shown in place of a Stux.Group service that hasn't been configured yet. It points visitors back to Stux.Group and its social channels.

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [servicepage.stux.group](https://servicepage.stux.group)

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/StuxGroup/servicepage.git
   ```

2. Open `index.html` in your browser or deploy to your hosting provider

## Customization

Edit the HTML files to:

- Update the message
- Add your branding and logo
- Customize colors and styling
- Include additional links

## Deployment

This project uses GitHub Pages and is automatically deployed to [servicepage.stux.group](https://servicepage.stux.group).

## Local preview

Run `./dev-server.sh` (or `dev-server.bat`, add a port as the last argument) to serve the site at `http://127.0.0.1:8000` the way GitHub Pages does, with the dev-mode banner on. Add `--no-dev-mode` to see it exactly as production does, or `?banner=soon,maintenance,site` to preview the other banner types. It uses PHP 7.4's built-in server (set `PHP_BIN` to pick another PHP).
